# 경고 철회 판단기: Claude가 직접 정한 것 (FR-RPT-105, 11/11)

경고 철회 판단기 정확도를 잴 때 팀 확인 없이 Claude가 정한 것들이다. 숫자와 순위는 [경고철회-판단기-순위.md](경고철회-판단기-순위.md).

정확도 숫자는 아래 판단 위에 서 있다. 바꾸면 숫자도 바뀐다.

| 무엇 | 정한 내용 | 왜 | 확인할 사람 |
|---|---|---|---|
| 사례 70개 | 모두 Claude가 만든 가짜. 실제 학생 글이 아님 | 시범 운영 전이라 실제 철회 요청이 없음 | 시범 운영 뒤 실제 요청으로 다시 재기 |
| 사례마다 정답 | 70개 정답(철회/유지)을 Claude가 붙임. 큰 기준 두 개(비품만 남음=철회, 본인 인정=유지)만 지영 확정 | 기준을 사례 하나하나에 적용한 것은 Claude 판단 | 팀원이 사례 몇 개 골라 정답에 동의하는지 보기 |
| "인정"의 범위 | 문제 된 결과(시끄러웠다, 어질러 둔 채 나왔다)를 인정해야 인정. "열었다가 닫았다", "쏟았지만 닦았다"는 인정 아님 | 행동만 인정하고 결과를 부인하면 사실 확인이 안 됨 | 지영 |
| 허위 신고 경고(FALSE_REPORT) | 학생 신고 경고와 같은 원칙. 학생이 착각을 인정하면 유지 | 기존 지시문 4번과 같게 | 지영 |
| 기준과 같은 확신도 | 0.80 = 기준 이상 → 유지 | `warn-min-confidence` 이상이면 경고하는 core 코드와 같게 | - |
| 방 비품 목록 | chair, desk, table, dining table, whiteboard, monitor, tv, trash can, clock, air conditioner, couch, bench | 실제 방 비품과 카메라 이름을 몰라 일반 스터디룸 기준으로 가정 | 수연(물건 이름), 지영(실제 방 비품) |
| 점수 세는 법 | 판단기 답이 아니라 학생에게 실제 적용되는 결정으로 셈(유지라도 확신도 0.8 미만이면 철회) | 학생이 실제로 받는 결과가 중요해서 | - |
| 심각 오류 | "철회해야 할 걸 유지"만 셈. "유지해야 할 걸 철회"는 보통 오류 | 받지 않아야 할 벌칙이 더 큰 피해(확인 불가 = 벌칙 없음 원칙) | - |
| 503 다시 시도 | 5xx면 1초·2초 쉬고 두 번 더. 429는 다시 안 함 | 503은 잠깐 뒤 대개 됨. 429는 다시 해도 한도만 씀 | - |
| holdout 15개 | 고치는 동안 결과를 안 보고 마지막에 한 번만 잼 | 시험 문제를 외워서 맞춘 게 아닌지 보려고 | - |
| 새 사례 20개에서 틀린 N13 | 고치지 않고 그대로 둠 | 고치면 처음 보는 사례 시험이 아니게 됨. 고칠지는 지영 결정 대기 | 지영 |
